# 📊 Employee Dataset Analysis Project

## 📖 About Project

This project is based on **Employee Dataset Analysis using Microsoft Excel**.  
The main purpose of this project is to analyze employee-related data and generate meaningful insights using Excel features and functions.

The dataset contains employee information such as:

- Employee ID
- Employee Name
- Department
- Salary
- Gender
- Age
- Experience
- Joining Date
- Performance Rating

---

# 🚀 Objectives

- Analyze employee performance
- Manage employee records
- Generate salary reports
- Identify department-wise statistics
- Create interactive dashboards
- Improve data analysis skills using Excel

---

# 🛠️ Tools & Features Used

- Microsoft Excel
- Pivot Tables
- Charts & Graphs
- Conditional Formatting
- Data Validation
- Excel Formulas & Functions
- Sorting & Filtering
- Dashboard Design

✅ Department-wise Salary Analysis
